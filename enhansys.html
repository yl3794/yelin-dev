Enhansys

As a Backend Developer Intern at Enhansys, an energy storage startup, I built the pipeline that brings years of Italian electricity market data into one database. Using parallel requests and Docker workers, it loaded more than 1.27 million historical records in under an hour. I replaced manual scripts with Apache Airflow, which runs all 23 data sources on schedule and retries automatically when a source fails, and I made every write safe to repeat so retries never create duplicates. I also standardized the data cleaning with dbt, cutting manual fix-up work by 56%.
