Real-time pipeline

A personal project where I built the part of a recommendation system most people never see: the pipeline that turns clicks into fresh ranking signals. Kafka streams user events, Flink keeps a running summary for each user, and a FastAPI service serves those features from Redis. It handles 5,000 events per second, and updating only what changed cut processing time by 65%. Redis caching and connection pooling brought the slowest responses down from 92 ms to 51 ms. Everything runs on AWS, set up with Terraform and monitored with Prometheus and Grafana.
